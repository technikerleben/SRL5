Gesprächsbegleiter

Ein roter Faden, kein starres Formular.

Wähle nur die Module, die heute passen. Du kannst jederzeit überspringen, frei notieren und am Ende eine kurze Vereinbarung für das nächste Gespräch festhalten.

Grundidee

Beziehung und aktueller Bedarf gehen vor Vollständigkeit.

Das letzte Ziel wird beim nächsten Gespräch automatisch wieder aufgegriffen.

Für Schülerdaten am besten nur Vorname oder Kürzel verwenden.

1. Gespräch anlegen

Ein Kürzel reicht. Bereits bekannte Namen erscheinen beim Tippen.

2. Module auswählen

Die Reihenfolge ist ein Vorschlag. Im Gespräch kann jedes Modul übersprungen werden.

Aktuelles Protokoll

Gespräch abschließen

Prüfe die Kurzfassung. Leere oder übersprungene Module werden nicht in den Verlauf übernommen.

Gesprächsverlauf

Wähle ein Kind aus. Ziele und Vereinbarungen lassen sich so über mehrere Gespräche verfolgen.

Daten & Backup

Die Gesprächsdaten werden ausschließlich im lokalen Browser-Speicher dieses Geräts abgelegt. Sie werden nicht an GitHub oder einen Server gesendet.

Backup

Exportiere regelmäßig eine Sicherungsdatei. Sie enthält die gespeicherten Gesprächsprotokolle im JSON-Format.

Lokale Daten löschen

Nur verwenden, wenn vorher ein Backup erstellt wurde oder die Daten nicht mehr benötigt werden.
