# Spiel-Bar der Klasse 5.3

- `index.html`: touchfreundliche Präsentation für die Klassen-AG
- `otter-mit-spiel.png`: Otterillustration auf der Startfolie
- `spielbar.png`: Querformatübersicht auf der zweiten Präsentationsfolie
- `handout.html`: bearbeitbare Graustufen-Druckvorlage des zweiseitigen Handouts
- `assets/otter-spielecheck-graustufen-druck.png`: tonerfreundliche Otter-Vignette
- `output/pdf/Handout_Spiel-Bar_Klassen-AG.pdf`: druckfertiges Graustufen-Handout im Format A4
- `output/pdf/Handout_Spiel-Bar_grafisch_graustufen.pdf`: zweiseitige PDF aus den grafisch gestalteten Bildseiten
- `output/pdf/Uebersicht_Spiel-Bar_A4.pdf`: A4-Übersicht zu Idee, Ausleihe und Rückgabe
- `output/bilder/Uebersicht_Spiel-Bar_Querformat.png`: Querformat-Übersicht für Bildschirm oder Schild
- `output/bilder/Handout_Spiel-Bar_Seite_1_graustufen.png`: grafisch gestaltete Bildfassung von Seite 1
- `output/bilder/Handout_Spiel-Bar_Seite_2_graustufen.png`: grafisch gestaltete Bildfassung von Seite 2

Die Präsentation funktioniert ohne externe Bibliotheken und verlinkt das PDF direkt in der unteren Navigationsleiste.
