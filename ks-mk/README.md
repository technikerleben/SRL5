# KS-MK · Jahrgang 5

Zentrale Ablage für die **Klassenstunde Medienkompetenz** im Jahrgang 5.

## Einstieg
- `index.html` — Lehrkraft-Cockpit
- `SKILL.md` — verbindliche Projektgrundlage

## Geplante Struktur
- `steuerung/` — Lernpass, Hilfeweg, Routinen, Partnerrollen, Reflexion
- `s0/` — gemeinsamer Einstieg
- `m1/` bis `m7/` — Pflichtmodule
- `wahlmodule/` — W1 bis W4
- `lehrkraft/` — Lösungen, Checks, Übersichten
- `schueler/` — späterer Lernnavigator und digitale Übungen
- `assets/` — gemeinsame Grafiken und Symbole

Unterordner werden angelegt, sobald dort erstmals Material entsteht. So bleiben keine leeren Strukturen im Repository.

Beispiel: `KS-MK_Jg5_M4_A2_Suchbegriffe.pdf`
